# Production VPS Checklist

## Before deployment

- [ ] OS updated
- [ ] SSH access tested
- [ ] Firewall reviewed
- [ ] Required ports documented
- [ ] DNS configured
- [ ] TLS plan prepared
- [ ] Backups configured and tested
- [ ] Monitoring configured
- [ ] Application logs available
- [ ] Disk capacity checked
- [ ] Recovery access confirmed

## Before major changes

- [ ] Current configuration backed up
- [ ] Database backup verified
- [ ] Rollback procedure known
- [ ] Impact understood
- [ ] Change documented

## After changes

- [ ] Service status checked
- [ ] Logs reviewed
- [ ] Ports verified
- [ ] Application tested
- [ ] DNS/TLS tested where applicable
- [ ] Resource usage checked
- [ ] Recovery state confirmed

A production change is incomplete until the result has been verified.
