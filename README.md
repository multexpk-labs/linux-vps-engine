# Linux VPS Engineering

Practical Linux VPS engineering, administration, optimization, security, troubleshooting, and production operations.

## What this repository covers

- Linux server administration and VPS lifecycle
- SSH, users, groups, permissions and sudo
- CPU, RAM, swap, processes and load analysis
- Storage, filesystems, disk and inode management
- systemd services and timers
- Networking, ports, routing and DNS
- Nginx, OpenLiteSpeed, PHP-FPM and application runtimes
- MariaDB/MySQL operational practices
- TLS/SSL and Let's Encrypt
- Firewalling and defensive hardening
- Logs, monitoring, backups and recovery
- Production troubleshooting
- Bash and Python automation

## Engineering method

    Observe → Measure → Identify → Test → Change → Verify → Document

## Repository map

- docs/ — engineering guides and checklists
- bash/ — reusable Linux diagnostic scripts
- python/ — automation and reporting utilities
- php/ — application health examples
- examples/ — configuration examples

## Safety

Use these techniques only on systems you own or are authorized to administer.

Never publish credentials, private keys, API tokens, customer information, internal inventories, or other sensitive production data. Review destructive commands before execution and keep tested backups before major changes.

## Learning path

Linux CLI → processes → permissions → storage → networking → SSH → web servers → databases → TLS/DNS → monitoring → backups → automation → production operations.
